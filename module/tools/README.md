# Bundled tools

Binaries are **not committed**. A release pipeline must place them under
`module/tools/bin/` before a real module is packaged; `build/build-tools.sh`
only compiles `dsh-mount-ro-recursive`.

- `losetup` — util-linux, must support `--sector-size` and `--direct-io=off`
- `mke2fs`, `e2fsck`, `resize2fs` — e2fsprogs
- `dsh-mount-ro-recursive` — tiny static helper using
  `mount_setattr(2)` + `AT_RECURSIVE` for `/apex`, `/linkerconfig`,
  `/metadata`, `/mnt/vendor/persist`, `/mnt/vendor/qmcs`
- `unshare` — util-linux, must support `--propagation` and `--mount`
- `nsenter` — util-linux, must support `--mount`
- optional: GNU `cp`/`tar`, static `busybox`

`doctor` reports missing tools as WARN; `doctor --for-apply` reports them as
FAIL. `tools/bin` is generated by `build/build-tools.sh` and is not committed.
