# Bundled tools

Binaries are **not committed**. A release pipeline must place them under
`module/tools/bin/` before a real module is packaged; `build/build-tools.sh`
only compiles `dsh-mount-ro-recursive`.

- `losetup` — optional util-linux variant with `--sector-size`/`--direct-io=off`;
  Android toybox `losetup` fallback is wired
- `mke2fs`, `e2fsck`, `resize2fs` — e2fsprogs
- `dsh-mount-ro-recursive` — tiny static helper using
  `mount_setattr(2)` + `AT_RECURSIVE` for `/apex`, `/linkerconfig`,
  `/metadata`, `/mnt/vendor/persist`, `/mnt/vendor/qmcs`; also supports
  `--make-rprivate PATH`
- `unshare`/`nsenter` — optional util-linux variants; Android toybox fallback (`-m -u`, `-t PID -m`) is already wired
- optional: GNU `cp`/`tar`, static `busybox`

`doctor --for-apply` fails only for tools the fallback cannot replace
(`dsh-mount-ro-recursive`, e2fsprogs); util-linux variants are preferred when
present. `tools/bin` is generated by `build/build-tools.sh` and is not committed.
